## ¿Que funcionó bien?
El uso de historias de usuario permitió organizar las funcionalidades principales de la aplicación antes y durante el desarrollo.
También funcionó correctamente la utilización de GitHub para almacenar el código y llevar un registro de los cambios realizados.

## ¿Qué fue difícil/qué costo trabajo?
Una de las principales dificultades fue organizar el código de manera que la interfaz gráfica y las operaciones de la base de datos pudieran trabajar correctamente.
